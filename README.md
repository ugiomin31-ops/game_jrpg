# 심연의 미궁 / Abyss Labyrinth

울리지 않는 여명의 종을 찾아, 네 동료가 미궁으로 내려가는 한국어 턴제 던전 RPG입니다. Unity 소스와 Blender·Python 제작 원본을 함께 보관합니다.

> **확인 범위 — 2026-10-07:** 아래 안내는 현재 연결된 소스 구현과 제한된 Unity 에디터 실행 관찰을 구분합니다. Windows 독립 실행 빌드·네이티브 입력과 Unity 전체 캠페인/엔딩 플레이는 아직 검증되지 않았습니다. 최신 근거와 제한은 [제품 사실 기록](memory/PRODUCT-TRUTH.md)을 기준으로 합니다.

## 실행과 모험의 흐름

- Windows 빌드 출력 대상: **`Build/Windows/AbyssLabyrinth.exe`**. 빌드가 생성된 뒤 이 파일로 실행하며, 실행 파일만 떼어 옮기지 말고 `Build/Windows/`의 데이터·런타임 파일을 함께 유지합니다. 이 경로는 빌드 코드의 지정값이지, 현재 빌드 성공의 증거는 아닙니다.
- 타이틀에서 **모험 시작 → 쉬움/보통/어려움 → 프롤로그 → 마을** 순서로 시작합니다. 기존 모험은 **이어하기**에서 자동 저장 또는 수동 슬롯을 선택합니다.
- 검사·마법사·궁수·성직자 네 명으로 탐험합니다. 마을의 여관, 상점, 대장간, 길드에서 회복·거래·제작·의뢰를 처리하고, 출발 메뉴에서 미궁에 진입합니다.
- 미궁은 자유 시점 이동이 아닌 **1인칭 격자 탐험**입니다. 문·열쇠·보물·함정·회복의 샘·계단과 배회 강적을 만나며, 발견한 구역은 지도에 표시됩니다.
- 전투에서는 공격·스킬·궁극기·아이템·방어·도주를 선택합니다. 약점 공격으로 실드를 깎아 **브레이크**를 만들면 적의 다음 행동을 막고 피해를 늘릴 수 있습니다. 자동 전투도 전투 메뉴/우측 상단 버튼에서 켜고 끕니다.
- B1F~B12F의 고정된 12층은 숲의 유적·빙결 동굴·불타는 동굴·망자의 묘소 네 바이옴으로 이어집니다. 최종 보스 뒤 이야기와 크레딧으로 연결되는 **유한 캠페인**이며, 이 마지막 Unity 경로의 실제 완주 확인은 아직 남아 있습니다.
- 로컬 데이터를 사용하는 **오프라인 1인용** 구성입니다. UI·이야기 언어는 한국어입니다.
- Windows 외에 **Android·iOS(가로 화면) 빌드 메뉴와 터치 조작**이 들어 있습니다. 실제 휴대폰 빌드·실행은 아직 확인되지 않았습니다.

## 조작

게임 창에 포커스가 있어야 입력을 받습니다. 패드 표기는 버튼의 위치 기준이며, 모든 컨트롤러 모델의 호환성을 검증했다는 뜻은 아닙니다.

### 메뉴·전투·이야기

| 동작 | 키보드 | 게임패드 | 마우스 |
|---|---|---|---|
| 선택 이동 | 방향키 / W·A·S·D | 방향 패드 / 왼쪽 스틱 | 항목에 포인터 이동 |
| 결정·버튼 실행 | Enter / 숫자패드 Enter / Space / Z | 남쪽 버튼(A/× 위치) | 왼쪽 클릭 |
| 취소·이전 화면 | Esc / X / Backspace | 동쪽 버튼(B/○ 위치) | 오른쪽 클릭 |
| 이전/다음 탭·전투 선택 페이지 | Q / E | LB / RB | 해당 탭·페이지 버튼 클릭 |
| 모험 수첩·캠프 열기/닫기 | Tab / C | Start / 북쪽 버튼(Y/△ 위치) | HUD의 수첩·캠프 버튼 |
| 긴 설명 스크롤 | 메뉴 상세 영역: 좌우 방향 입력 | 메뉴 상세 영역: 좌우 방향 입력 | 스크롤 영역에서 휠 |

- 이야기에서는 `다음`/`계속` 버튼을 결정하면 표시 중인 문장을 즉시 펼치고, 다시 결정하면 다음 페이지로 넘어갑니다. 위아래 입력으로 본문을 스크롤할 수 있습니다.
- 메뉴가 없는 탐험·마을에서는 취소 입력으로도 수첩/캠프를 엽니다. 전투 하위 선택에서 취소는 한 단계 뒤로 이동하며, 자동 전투 중 취소는 자동 전투를 멈춥니다. 전투 수첩은 입력 가능한 시점에만 열립니다.
- `UIInput`에는 Shift/I·패드 서쪽 버튼의 정보 액션 정의도 있지만, 현재 게임 화면에서 공통 정보 토글로 연결된 기능은 없으므로 별도 조작으로 안내하지 않습니다.

### 미궁 탐험 — 메뉴가 닫혀 있을 때

| 동작 | 키보드 | 게임패드 |
|---|---|---|
| 전진 / 후퇴 | W·↑ / S·↓ | 방향 패드 위 / 아래 |
| 좌회전 / 우회전 | A·← / D·→ | 방향 패드 왼쪽 / 오른쪽 |
| 왼쪽 / 오른쪽 옆걸음 | Q / R | LB / RB |
| 조사·상호작용 | E / Space | 남쪽 버튼 |
| 한 턴 대기 | .(마침표) | 서쪽 버튼(X/□ 위치) |

메뉴의 `E=다음 탭`과 탐험의 `E=조사`는 화면에 따라 다릅니다. **탐험 이동은 패드 방향 패드로 조작하며, 왼쪽 스틱 이동이나 마우스 자유 시점 회전은 구현되어 있지 않습니다.** 마우스로는 오른쪽 아래 3×3 HUD 패드(옆걸음·전진·옆걸음 / 회전·조사·회전 / 대기·후퇴·지도)와 미니맵 아래 캠프 버튼을 사용할 수 있으며, 이동 버튼은 누르고 있으면 계속 걷습니다. 지도는 HUD의 지도 버튼, 미니맵 클릭, 또는 수첩/캠프의 지도 항목으로 엽니다.

### 터치 (휴대폰·태블릿)

| 화면 | 동작 |
|---|---|
| 마을 | 빈 곳을 누른 채 끌면 그 자리에 나타나는 가상 스틱으로 이동(끝까지 밀면 달리기), 가까운 주민·시설을 탭하면 대화 |
| 미궁 | 오른쪽 아래 패드 버튼(누르고 있으면 연속 이동), 화면을 위/아래로 튕기면 전진/후퇴, 좌/우로 튕기면 회전, 미니맵 탭으로 지도 |
| 전투 | 명령을 탭해 선택, 대상 선택 중에는 적·아군 카드를 한 번 탭하면 미리보기, 한 번 더 탭하면 결정. 우측 상단에서 속도(1x/1.5x/2x)·자동 전투 전환 |
| 메뉴·목록 | 항목 탭으로 결정, 목록을 위아래로 끌어 넘기기, 이야기는 화면 탭으로 진행. Android 뒤로 버튼은 취소 |

터치 화면에서는 버튼·목록 행이 손가락 크기에 맞게 커지고, 좁은 16:9 휴대폰·4:3 태블릿에서는 동료 카드가 자동으로 줄어 이동 패드와 겹치지 않습니다. 휴대폰 설정에는 해상도 대신 **배터리 절약(30fps)**이 있습니다.

## 저장과 설정

- 저장 폴더는 **`Application.persistentDataPath/campaign/`**입니다. `autosave.json`과 수동 슬롯 `slot_1.json`~`slot_3.json`, 별도 설정 `preferences.json`을 사용합니다. 백업할 때는 이 폴더 전체를 보관합니다.
- 자동 저장은 마을/미궁 진입, 층 이동, 조우 시작 전과 전투 결과 처리 등 지정된 시점에 수행됩니다. **모든 걸음·모든 변경이 즉시 자동 저장되는 것은 아닙니다.** 종료 시에는 타이틀·전투를 제외한 진행을 저장하도록 구현되어 있습니다.
- 수첩/캠프에서 세 개의 수동 슬롯에 저장할 수 있습니다. 전투 중 수동 저장은 불가하며, 전투 전 자동 저장은 유지됩니다. 미해결 조우를 불러오면 해당 전투를 다시 시작하지, 전투 도중의 턴을 복원하지는 않습니다.
- 새 모험은 자동 저장을 덮어쓰지만 수동 슬롯은 유지합니다. 불러오기·타이틀 복귀 시 저장하지 않은 진행은 잃을 수 있습니다.
- 전체/음악/효과 음량, 음소거, 창/전체 화면, 해상도(1280×720~2560×1440), 전투 속도(1x/1.5x/2x, 전투 중 우측 상단 버튼으로도 전환), 대사 속도, 연출 움직임 줄이기를 설정할 수 있습니다. 변경은 즉시 적용·저장하도록 연결되어 있으며, 화면 모드·해상도 적용은 에디터 밖에서만 수행됩니다. Windows에서의 실제 화면 전환은 아직 확인되지 않았습니다.

## 소스에서 실행·빌드

1. Unity Hub에서 **Unity 6000.3.25f1**과 **Windows Build Support (Mono)**를 준비합니다. 프로젝트 루트(이 파일이 있는 폴더)를 열고 패키지 복원·임포트·컴파일이 끝나기를 기다립니다.
2. 플레이 모드를 끈 상태에서 **`Abyss > Prepare Game`**을 실행합니다. `Assets/_Game/Scenes/Main.unity`와 런타임 리소스를 준비하는 기존 편집기 메뉴입니다.
3. **`Abyss > Validate Production Content`**로 데이터가 참조하는 제작 모델 리소스를 확인합니다. `Main.unity`를 열어 Play로 에디터에서 실행할 수 있습니다.
4. Windows 출력은 **`Abyss > Build Windows`**를 사용합니다. 이 메뉴는 준비·콘텐츠 확인 후 Windows x64/Mono 빌드를 `Build/Windows/AbyssLabyrinth.exe`로 요청합니다. 빌드 완료 로그와 실제 Windows 실행을 별도로 확인해야 합니다.

5. 휴대폰용은 Unity Hub에서 **Android Build Support(IL2CPP·OpenJDK·Android SDK & NDK)** 또는 **iOS Build Support**를 추가한 뒤 **`Abyss > Build Android (APK)`**, **`Abyss > Build Android (Google Play AAB)`**, **`Abyss > Build iOS (Xcode project)`**를 사용합니다. 출력은 `Build/Android/AbyssLabyrinth.apk|.aab`, `Build/iOS/`(Mac의 Xcode에서 서명·실행)입니다. 가로 화면 고정, IL2CPP·ARM64, ASTC 텍스처, Android 7.1(API 25) 이상으로 설정되며, 휴대폰은 `Mobile` 품질 단계(URP `Mobile_RPAsset`, 렌더 스케일 0.8)를 씁니다. 배치 빌드: `Unity -batchmode -quit -projectPath . -executeMethod Abyss.EditorTools.AbyssProjectSetup.BuildAndroid`. 스토어 업로드용 AAB에는 별도의 키스토어 서명 설정이 필요합니다.

이미 제작된 게임 리소스를 사용하는 Unity 실행/빌드에 Blender·Python 재생성은 필요하지 않습니다. 제작 원본을 수정할 때만 아래 경로를 사용합니다.

| 경로 | 역할 |
|---|---|
| `Assets/_Game/Scripts/Logic/` | 전투·미궁·성장·마을 서비스·저장 상태 규칙 |
| `Assets/_Game/Scripts/Runtime/`, `UI/`, `Presentation/` | 화면 전환, 3D 월드, 입력/UI, 오디오와 전투 연출 |
| `Assets/_Game/Resources/Data/` | 영웅·적·기술·장비·아이템·층·의뢰·한국어 텍스트 |
| `Blender/` | 3D 생성기, `blend/` 편집용 결과, `preview/` 검수 이미지. 상세 계약은 [Blender 안내](Blender/README.md) 참조 |
| `Tools/ui/`, `Blender/ui/render_icons.py` | UI 스프라이트와 실제 3D 모델 기반 초상화·아이콘 제작 |
| `Tools/vfx/` | 이펙트 텍스처와 리소스 정의 생성 |
| `Tools/audio/` | 현재 사용 중인 음악·징글·효과음의 합성·내보내기 원본 |
| `Tools/LogicTests/`, `Tools/logic_test.py` | Unity 화면과 분리된 C# 로직 회귀 검사 도구 |

Blender 생성기는 프로젝트 루트에서 Blender 실행 파일을 직접 지정하여 실행합니다. 예를 들어 PowerShell에서 적 모델을 재생성하는 명령은 다음과 같습니다(현재 리소스를 다시 쓰므로 제작 수정 때만 사용).

```powershell
& "C:\Users\User\Tools\Blender\blender.exe" -b --factory-startup -P Blender/enemies_a/generate_all.py
```

생성기는 라이브러리 경로를 스크립트 위치 기준으로 찾으므로 Linux·macOS의 Blender 5.2에서도 같은 명령(`blender -b --factory-startup -P …`)으로 실행됩니다. 특정 적만 다시 만들 때는 `-P Blender/enemies_a/generate_all.py -- --asset sprout`처럼 id를 지정합니다.

무기·장비는 `Blender/weapons/generate_all.py`, 환경은 `Blender/environment/regenerate_all.py`, 초상화·아이콘은 `Blender/ui/render_icons.py`가 담당합니다. Python UI/VFX 제작 도구는 NumPy·Pillow를, 오디오 원본은 NumPy·SciPy·pyloudnorm·SoundFile을 사용합니다. 현재 오디오 출력 진입점은 `python Tools/audio/export.py`이지만, **다음 오디오 제작 시에는 [agent-audio](https://github.com/AIEGOBOT/agent-audio)를 참고한다는 결정**이 있습니다. 지금 설치·실행하거나 기존 음원을 교체하라는 뜻은 아니며, 도구의 조건은 아직 검증되지 않았습니다([제작 결정](memory/DECISIONS.md)).

## 관찰된 실행 범위

담당 통합 작업에서 보고한 **Unity 에디터의 보통 난이도 B1 자연 조우 1건** 기준입니다. 전체 시나리오나 반복 신뢰성 검증으로 확대 해석하지 않습니다.

- 3라운드 승리와 보상 확인 후 보유 골드 214 G.
- 상점에서 `armor_chain` 구매: 골드 214 → 144 G.
- 장비 해제/재장착: 장비 가방 수량 1 → 2 → 1.
- 필드 회복: 검사 HP 142 → 165, 회복 물약 4 → 3.
- 설정 메뉴에서 전체 음량 0.5 선택, 저장된 값 0.5 확인.

이 기록은 Windows 실행, 모든 보스·연출·시설·설정, Unity 엔딩 완주, FPS/최소 사양 또는 배포 승인 증거가 아닙니다.

## 크레딧과 배포 전 확인

타이틀/수첩의 **크레딧**에서 제작 과정과 라이브러리·글꼴 고지를 볼 수 있습니다. 전문은 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)와 `Assets/_Game/Resources/Credits/`에 보존되어 있습니다. 현재 제작 과정은 AI 보조 코드·Blender/Python 에셋 제작, Python 합성 오디오, Unity/URP/uGUI/TextMesh Pro 통합으로 기록되어 있습니다. 도구 이름은 보증·후원 또는 저작권 승인 표기가 아닙니다.

출시 전에 실제 담당자가 확인할 항목:
