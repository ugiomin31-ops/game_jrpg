## Exact prompt (one request, 4 images)

Generate FOUR separate standalone images… Original game UI mock-up for a modern Korean urban-fantasy hunter RPG on a landscape phone (20:9). Stylish, high-contrast, kinetic layout inspired by modern JRPG menu design principles (asymmetric diagonal composition, bold parallelogram plates, strong typography, motion implied by slants) — but an ORIGINAL look: palette deep navy, ink black, cyan and violet with one coral-red accent; no Persona or Metaphor logos, characters, fonts, icons or red-black colour scheme; Korean UI text; clean 3D toon battle scene behind the UI. Screen: town_hud — guild street, slanted header ribbon (goal), facility list as plates, slim party plates, zoom buttons.
