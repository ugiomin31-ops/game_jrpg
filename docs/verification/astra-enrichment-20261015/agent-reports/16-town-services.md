## 발견 1 — P3: 보상으로 99개를 넘긴 재고에 실행 불가능한 판매 수량이 표시됨

**위치:** `Assets/_Game/Scripts/Logic/Game/TownServices.cs:226` (아이템 판매가 99개 초과를 거부), 연결 UI `Assets/_Game/Scripts/UI/Screens/GameUI.Town.cs:119-121,129-137`.

**도달 가능한 재현 절차:**

1. 도감 10종 토벌 보상을 아직 받지 않은 상태에서 강화석을 99개 보유한다. 강화석은 처음부터 상점에서 구매할 수 있고, 개당 80·스택 99·판매가 40이다 (`Assets/_Game/Resources/Data/items.json:185-196`).
2. 10종 토벌 보상을 받는다. 보상은 강화석 3개이며 (`TownServices.cs:489`), 수령은 `AddContent`를 호출한다 (`TownServices.cs:557-559`). `GameState.cs:243-246,264-267`은 수량을 그대로 더하므로 재고는 102개가 된다.
3. 상점 판매에서 강화석을 선택한다. UI는 재고 전부를 최대 수량으로 전달하므로 100·101·102개 선택과 거래 확인까지 허용한다.
4. 예를 들어 102개 판매를 승인하면 `SellItem`이 `invalid_count`로 거부한다. 표시된 4,080만원 거래는 실행되지 않는다.

**영향:** 정상 보상 수령으로 생긴 재고에 대해 상점이 승인 가능한 것처럼 제시한 판매가 실패한다. 골드나 아이템 손실은 없으며, 99개 이하로 나눠 팔면 우회할 수 있다. 입력 오염이나 정수 최댓값을 요구하지 않는 UI/서비스 수량 계약 불일치다. 수정은 수행하지 않았다.
