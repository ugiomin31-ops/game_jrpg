## Unity 확인 순서

1. 도현·지호·민준·서아·유나 중 한 명을 쓰러뜨립니다. 뒤로 넘어져 누워야 하며, 시작할 때 몸 방향이 튀지 않는지, 바닥을 뚫거나 공중에 뜨지 않는지 확인합니다. 부활 아이템·스킬로 일으켜 자세가 튀지 않는지 봅니다. 1배속·2배속, 동작 줄이기 켬/끔.
2. Blender 리그 헌터(예: 보라)도 쓰러뜨리고 부활시켜 기존 동작이 유지되는지 확인합니다.
3. 전투에 쓰러진 헌터가 있는 상태로 일반 전투와 보스 전투에 들어가, 처음부터 누워 있는지 확인합니다.
4. 마을에서 키보드 이동(조깅), Shift(질주), 터치 스틱 반쯤(걷기)으로 이동하며 발이 미끄러지는지 봅니다. 동료 셋도 같이 확인합니다.
5. 방어 → 적에게 맞기 → 다음 턴 시작까지 방어 자세가 유지되는지 봅니다.
6. 빙결·수면·브레이크를 건 적을 때려 봅니다. 빙결은 멈춤, 나머지는 느린 대기, 피격 반응은 정상 속도여야 합니다.
7. 근접 공격 3회(Attack/Slash/Thrust 순환)로 도착과 타격 타이밍을 봅니다.
8. 도현 「각성 이연참」, 서아 광역 주문, 도주 실패/성공, 보스 페이즈 전환(2배속)을 확인합니다.
