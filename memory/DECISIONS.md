# 제작 결정

## 향후 오디오 제작 도구

- 사용자 지시: "오디오 생성은 https://github.com/AIEGOBOT/agent-audio 이거 쓰라네 지금 당장하는게 아니라 나중에 제작할때 이거 참고해"
- 다음 오디오 제작 때 `AIEGOBOT/agent-audio`를 참고한다.
- 현재는 설치·실행하거나 기존 제작 오디오를 교체하지 않는다.
- 해당 도구의 기능, 비용, 라이선스 및 배포 조건은 아직 조사하거나 검증하지 않았다. 실제 도입 시 확인한다.

## 계정과 전체 품질 확인

- 사용자 지시: 한도에 도달하면 다른 Codex 계정으로 전환하고, UI·게임성·그래픽·애니메이션/동작 전환·게임 진행을 전체적으로 제대로 확인한다.
- `codex login status`: ChatGPT 로그인 상태. 별도 Codex CLI 로그인과 현재 OMP 실행 환경 계정은 같은 것으로 단정하지 않는다.
- 현재 실행 환경의 `omp usage --provider openai-codex --redact --no-extensions` 조회에서는 저장 계정 2개, 5시간 사용량 각각 5%와 100%가 관찰됐다. 이는 조회 시점 값이며 현재 요청에 사용된 계정 ID나 이후 한도를 뜻하지 않는다.
- OMP provider 문서는 저장 OAuth 계정의 자동 순환을 지원한다고 명시한다. 현재 사용 가능한 다른 저장 계정이 있으므로 불필요한 로그아웃·인증 교체를 하지 않고, 실제 한도 발생 시 대체 계정 재시도 결과를 확인한다. 계정 토큰이나 비밀값을 출력하지 않는다.
- 컴파일·모델 개수·단일 B1 승리만으로 전체 품질이나 완주를 판정하지 않는다. 실제 UI·진행·보스·엔딩과 애니메이션 전환의 관찰 증거, 발견 결함과 수정 후 실행 결과를 구분한다.
